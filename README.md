# Rune Puzzle — Elder Futhark mini-games

This small web project contains three mini-games/apps to explore Elder Futhark runes:

- Write your name in runes
- Translate runes to Latin transliteration
- A simple match-the-rune puzzle

Files:

- `index.html` — main page
- `styles.css` — styling
- `app.js` — rune data and game logic

How to run

1. Open `index.html` in your browser (double-click or open with your browser).
2. Try the "Write Name" tab and click "Render in Runes".
3. Use the "Translate" tab to paste runes and see a latin transliteration.
4. Start the puzzle in the "Rune Puzzle" tab.

Notes and next steps

- This is a lightweight starter. Suggested improvements:
  - Better rune font or SVG icons for styling
  - Audio, levels, persistence (localStorage)
  - More accurate transliteration rules for historical variants

Enjoy exploring the runes!
